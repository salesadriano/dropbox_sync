# Release v2.3.0-bash42 — Linha Legada para bash 4.2 e 4.3

Linha de produto para hosts com bash 4.2 ou 4.3 (RHEL/CentOS 7, Amazon Linux 2), mantida no branch `support/bash-4.2`. Tem os mesmos comandos e recursos da v2.3.0. Quem tem bash 4.4 ou mais novo continua na linha principal (v2.3.0).

## O que ha de novo

- **Roda no bash 4.2 e 4.3.** A suite completa foi validada no CentOS 7 (bash 4.2.46, curl 7.29).
- **O `install.sh` escolhe a linha pelo bash do host:** 4.4 ou mais novo instala a principal; 4.2 e 4.3 instalam esta linha; abaixo de 4.2, recusa. Para atualizar, rode o `install.sh` de novo. A troca de linha (por exemplo, depois de atualizar o bash) e avisada, e a credencial e o estado sao preservados.
- **O `dbx` em bash antigo demais** sai com `3` e diz como reinstalar, antes de carregar qualquer biblioteca.

## Correcoes (tambem na v2.3.0)

- **Seguranca de dados sem a localidade `C.UTF-8`** (o CentOS 7 nao a tem):
  - `sync --espelhar` apagava o arquivo recem-enviado quando so a caixa de uma letra nao ASCII diferia (`Éa.txt` e `éa.txt`, que no Dropbox sao o mesmo arquivo). Agora nenhum caminho fora do ASCII e apagado sem a localidade; um aviso diz quantos foram mantidos.
  - `--incluir` e `--excluir` com nome ou padrao nao ASCII falham fechado: o que nao pode ser comparado nao entra no escopo, e o `--excluir` protege a mais.
- **Analise de JSON linear:** respostas grandes de listagem ficam muito mais rapidas (1600 entradas: de 4,4 s para 0,5 s no bash 4.2).
- **Especificas do bash 4.2:** o eco do terminal volta depois de Ctrl-C na pergunta de senha, o calculo do `content_hash` fica linear, e um arquivo de corpo ilegivel e recusado antes da rede (o curl 7.29 o enviava vazio).

## Limites desta linha

- Sem a localidade `C.UTF-8`, a comparacao sem caixa so vale para letras ASCII: `É` e `é` contam como nomes diferentes. O bash 4.2 nao dobra outras letras nem com `en_US.UTF-8`. Com `--espelhar`, esses caminhos nao sao apagados.
- Recurso novo da linha principal chega aqui so por backport sob demanda.

## Instalacao

```bash
curl -fsSL https://raw.githubusercontent.com/salesadriano/dropbox_sync/master/install.sh | bash
```

Em bash 4.2 ou 4.3, o instalador baixa esta linha sozinho. Para instalar pelo pacote, use `dropbox_sync-2.3.0-bash42-linux.tar.gz` desta release.
